# Exploratory Data Analysis (EDA) Project

This repository contains a comprehensive Exploratory Data Analysis (EDA) project. The analysis aims to uncover patterns, detect anomalies, test hypotheses, and validate assumptions through statistical summaries and graphical representations.

It includes two data analyses based on the following datasets:

Book Sales Data, imported from 'https://www.kaggle.com/'
Olympics Data, imported from 'https://www.kaggle.com/'
This project helps me enhance my understanding of data analysis, select appropriate visualizations, and improve my exploratory data analysis skills.
